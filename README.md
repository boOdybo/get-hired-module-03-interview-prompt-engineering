## Prompt Bank
The Prompt Bank Builder collects the five edited prompts during the current browser session and can export them as a TXT file. Download the TXT to keep a persistent copy after closing the presentation.

## Important
Use real student experience in interview stories. The fictional case in the presentation is only a teaching simulation. Never invent achievements, numbers, responsibilities, or employment history.
